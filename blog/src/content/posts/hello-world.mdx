This is where longer writing will live. [Notes](https://notes.elimelt.com) stays the place for reference material; posts here are dated and meant to be read start to finish.

Posts are Markdown, so most of the time it's just text, `inline code`, and the occasional code block:

```ts
const walk = (x: number, step: number) => x + (Math.random() - 0.5) * 2 * step;
```

When a post needs something you can poke at, it imports a component and drops it in:

<Figure caption="Each dot takes an independent random step every frame. Drag the slider to change the step size." wide>
  <RandomWalk walkers={300} />
</Figure>

That one is a plain custom element with no framework, and its script only loads on pages that use it.
