# Agent Guide

This repository holds several sites. Each has its own guide; read the one for
the directory you are working in.

- `notes/` is the notes site (notes.elimelt.com). Read `notes/AGENTS.md`.
- `docs/` has its own `docs/AGENTS.md`.

To enhance, improve, deepen or rework a note, or to add an interactive figure
to one, read `.claude/skills/enhance-note/SKILL.md` and follow it step by step.
It is the full process and applies to every agent, not only Claude.
